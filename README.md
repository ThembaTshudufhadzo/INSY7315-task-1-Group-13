# UbuhleBethu System Prototypes

This repository contains the source code and prototypes for both the web and mobile applications of the **UbuhleBethu** project.

---

##  Repository Structure

* **[`UbuhleBethu-Web/`](./UbuhleBethu-Web)**  
  ASP.NET Core MVC web application prototype developed in Visual Studio.
  * *Refer to the `README.md` inside this directory for setup, database configuration, and execution instructions.*

* **[`UbuhleBethu-Mobile/`](./UbuhleBethu-Mobile)**  
  Android mobile application prototype developed in Android Studio.
  * *Refer to the `README.md` inside this directory for build steps, dependencies, and emulator instructions.*

---

##  Quick Start

1. **Web App:** Open `UbuhleBethuConnectPro.Web.slnx` (or `.csproj`) inside `UbuhleBethu-Web` using Visual Studio and run the application.
2. **Mobile App:** Open the `UbuhleBethu-Mobile` project directory in Android Studio, sync Gradle, and run on a target device or emulator.
